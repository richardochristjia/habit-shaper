# Agent skills for Habit Shaper

Quick index of the skills and workflows we use in this repo.

## Repo-local skill

- `setup-matt-pocock-skills` — sets up the repo's issue-tracker, triage-label, and domain-doc conventions.

## Common skills

- `domain-modeling` — sharpen Habit Shaper vocabulary and record domain decisions.
- `code-review` — review changes against repo standards and the spec.
- `tdd` — implement changes test-first.
- `diagnosing-bugs` — debug failing or slow behavior.
- `codebase-design` — design modules, seams, and deep interfaces.
- `research` — gather facts from primary sources.
- `prototype` — build throwaway exploration prototypes.
- `ui-ux-pro-max` — design or review UI, layout, and accessibility.
- `grilling` — stress-test a plan or decision.
- `domain-forge` — grill the plan and update domain docs inline.
- `find-skills` — discover or install more skills.
